# Suite Core's Media Tools adapters

This subtree is the **Suite Core-owned integration boundary** for Media Tools (Rectools), not the optional add-on executable. It holds Media Import and HEVC Shrink admission, operation fences, durable shrink review persistence and maintenance checks/fencing. The global maintenance *diagnostic* now denies unresolved Import, HEVC Stage and HEVC Publish operations and Agent commands as well as their advertised capabilities. The durable global SQLite reservation freeze now fences Media Import, HEVC Stage and HEVC Publish in the same operation-creation transaction; HEVC effective capability and final Agent receipts recheck it. The protected child-lifetime run lock still covers Import only, not in-flight HEVC encoders: this diagnostic does NOT authorize package upgrades or removal. These classes reuse canonical Suite Core authentication, exact actor/backend grants, administrator desired state, SQLite operation identity, Agent generation and audit requirements.

General add-on registration, provider trust, administration and policy classes stay in `core/addons/`. Optional import/read-only Check/non-destructive HEVC Shrink implementations and isolated worker tests live under `addons/media-tools/`. Disabled packaging metadata stays under `modules/rectools/`. No runtime is activated by directory organization. No repair/smart_repair, cut, marks, rename or move.
