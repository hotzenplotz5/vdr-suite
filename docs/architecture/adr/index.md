[`docs/adr/index.md`](../../adr/index.md). Its two documents record prior
architecture direction; later numbered ADRs and source-verified closeouts govern
any differences in current runtime scope.

- [Early frontend OSD strategy](ADR-OSD-STRATEGY.md) — domain-first UI remains the
  primary model; later [ADR-0047](../../adr/ADR-0047-legacy-osd-compatibility-bridge.md)
  and [Phase 68 closeout](../../development/phase-68-closeout.md) define the isolated
  native-OSD compatibility bridge.
- [Early backend-federation strategy](ADR-BACKEND-FEDERATION-STRATEGY.md) — hypothetical
  TVHeadend mapping is not an implemented adapter; [ADR-0060](../../adr/ADR-0060-federated-vdr-suite-sharing-reciprocal-site-trust.md)
  distinguishes planned reciprocal site trust from implemented Agent-managed backends.
