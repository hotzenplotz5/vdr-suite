# Third-party data providers

## TVmaze

VDR-Suite can retrieve missing series artwork from
[TVmaze](https://www.tvmaze.com/) through the public TVmaze API.

TVmaze data is available under the Creative Commons Attribution-ShareAlike
license (CC BY-SA). VDR-Suite uses TVmaze only as a secondary artwork source;
TVScraper remains primary. The integration uses exact IMDb or TheTVDB series
identities and does not perform title-based matching.

VDR-Suite is an independent project and is not endorsed by or affiliated with
TVmaze. Keep this attribution and provider link when redistributing a build that
includes the TVmaze integration.

## TMDB

TMDB remains an optional provider that requires an operator-supplied API Read
Access Token. VDR-Suite does not distribute a shared TMDB credential. This
product uses the TMDB API but is not endorsed or certified by TMDB.
